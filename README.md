# Brew Haven ☕

A coffee shop website built using PHP, MySQL, HTML, and CSS.

## Features
- Customer registration and login
- Browse coffee products
- Add products to cart and update quantities
- Checkout and order storage
- Admin dashboard
- Add and edit products
- Manage product availability
- Customer discount functionality

## Technologies
- PHP
- MySQL
- HTML and CSS
- XAMPP

## Run Locally
1. Install XAMPP.
2. Copy the project into `htdocs`.
3. Start Apache and MySQL.
4. Create the `coffee_shop` database in phpMyAdmin.
5. Import the project's database SQL file.
6. Configure the database connection.
7. Open `http://localhost/coffee-shop/`.
